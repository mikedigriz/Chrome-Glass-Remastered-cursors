## Sharp at any size

**Version 2.0 redraws every cursor from scratch.** 1.x took the 2006 pictures and enlarged them with AI, and up close it showed. Now each cursor is drawn anew for every size, so it stays crisp even with the pointer made very big, and it still looks like yoyos' original.

<img src="https://raw.githubusercontent.com/mikedigriz/Chrome-Glass-Remastered-cursors/v2.0.0/assets/hero.png" alt="The 2006 arrow enlarged beside the 2.0 arrow drawn at full size">

## What's new

- **Crisp from small to huge**, 32 to 512 pixels. Not a single pixel comes from AI anymore.
- **Animations like the original:** light runs over the busy cursors, the arrow fades inside the "no" sign, a pen grows out of the handwriting cursor.
- **The "?" on Help** is now made of glass too.
- **Windows:** animated cursors stay sharp up to 128 px (was 96). New sizes for 125% and 175% display scaling. Installing over an old version replaces its files.
- **Linux:** the same new sizes. Hyprland support. On Debian and Ubuntu, picking the theme no longer falls back to the default one.
- **macOS:** 36 cursors instead of 12, including all resize arrows, the hands, and the copy and link arrows. Sharp up to 10x. The busy cursors animate.

<img src="https://raw.githubusercontent.com/mikedigriz/Chrome-Glass-Remastered-cursors/v2.0.0/assets/animations.webp" alt="The five animated cursors side by side">

## Download

| System | File | How |
|---|---|---|
| Windows 10/11 | `ChromeGlassRemastered-windows.zip` | unpack, right-click `Install.inf` → **Install**, then choose the scheme in mouse settings → **Pointers** |
| Debian / Ubuntu | `chrome-glass-remastered-cursors_2.0.0_all.deb` | `sudo apt install ./chrome-glass-remastered-cursors_2.0.0_all.deb` |
| Arch | `PKGBUILD` | `makepkg -si` next to it |
| Any Linux | `ChromeGlassRemastered-linux.tar.xz` | unpack into `~/.icons` |
| macOS 14+ | `ChromeGlassRemastered.cape` | open with [Mousecape](https://github.com/sdmj76/Mousecape-swiftUI) (not yet tried on a real Mac) |

**Coming from 1.x?** Just install over it. On Windows, choose the scheme again; on Linux, log out and back in.

Step-by-step instructions and help: [README](https://github.com/mikedigriz/Chrome-Glass-Remastered-cursors#installation). Checksums: `SHA256SUMS`.

Chrome Glass is [yoyos' work](https://www.deviantart.com/yoyos/art/Chrome-Glass-32252748) from 2006. This is an unofficial tribute; the artwork is not under the MIT license, see `NOTICE`.
